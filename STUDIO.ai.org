* VRAM LAW

6 GB ceiling (GTX 1660 SUPER). Models load strictly one at a time through
=gpu.gpu_model()=, which deletes and empties the CUDA cache on exit. Budgets:
whisper int8_float16 batch 8 ≈ 3.5 GB (auto-halves to 4 then 2 on CUDA OOM via
=with_oom_backoff=), alignment ≈ 1.5 GB, pyannote ≈ 2 GB, MADLAD int8_float16
≈ 3.3 GB. Every stage accepts CPU fallback, MADLAD via =--device cpu=.

* STYLE ENGINE EXACTS

- File resolution :: =--styles PATH= → =<video dir>/styles.toml= → =<project root>/styles.toml= (THE central file) → =~/.config/subtitle-studio/styles.toml= → built-in defaults (=stages.style.resolve_styles_path=; project root found by walking up to =pyproject.toml=).
- Resolution order :: =[default]= ← =[style.<preset>]= ← =[speaker.<key>]=, key is stable id or display name, id wins.
- Meta keys :: =play_res= ("video" or =[w, h]=) and =default_preset= (applied when no =--preset= is passed, resolved in =run_style=).
- Square box :: BorderStyle=4, =Outline= carries =padding.x=, glyph outline forced fully transparent or every glyph halos (found by frame inspection 2026-08-08).
- Rounded box :: NOT libass native. Layer-0 ={\p1}= rounded-rect drawing (bezier corners), sized from real glyph advances (=fonts.measure_line=, hmtx/upem, cached) plus =padding {x,y}=, so the text keeps its true stroke (BorderStyle=1). Requires a resolvable font file, otherwise a 0.52 em average estimate.
- Glow :: layer-1 copy of the text, =\bord stroke.width+glow.size=, =\3c= glow color, =\1a&HFF&= transparent fill, =\blur radius=. Layer-2 is the crisp text.
- Layered events pin with explicit =\pos= so libass collision handling never separates layers; overlap stacking shifts y by the previous block height.
- Colors :: config =#RRGGBB[AA]= to ASS =&HAABBGGRR=, ASS alpha INVERTED (=00= opaque). Inline tags use =&HBBGGRR&= without alpha.
- Freshness :: the style stage hash includes transcript, styles.toml, preset and position, so changing any re-runs exactly style and render.

* PITFALLS

- MADLAD-3B doubles short outputs ('Exactly. Exactly.'). Decoding params do NOT fix it, =collapse_repetition()= post-processing does (difflib halves ratio > 0.85 + consecutive duplicate sentences). Source text always survives in =source_text=.
- Mixed-language videos align word timestamps with the file-level language's wav2vec2 model, the other language's word timing is slightly looser.
- Language detection on short segments is unreliable, below 0.55 confidence or 2 words the segment inherits the file-level language (=langid.MIN_CONFIDENCE=).
- ffmpeg filtergraph paths need escaping (=render.escape_filter_path=), covers =' : , ; [ ]= and backslash. Real-world OBS filenames contain spaces.
- WhisperX pins torch tightly. The hedge: =[asr] engine = "faster-whisper"= switches engines without touching downstream stages.
- =--swap= requires exactly two detected languages, otherwise instruct =--to=.

* VERIFICATION

Gates for any change, in order:

1. =uv run pytest= green (47 tests, no models needed).
2. =uv run subtitle-studio run examples/sample.mkv --no-diarize --burn= then re-run, second pass must print skips for extract and transcribe.
3. Frame check on any styling change: =ffmpeg -ss T -i render.<track>.mp4 -frames:v 1 f.png= and LOOK at it (halo bug class is invisible in the .ass text).
4. VRAM on ASR/translate changes: =nvidia-smi --query-gpu=memory.used --format=csv -lms 500= while running, peak stays under 6 GB.
